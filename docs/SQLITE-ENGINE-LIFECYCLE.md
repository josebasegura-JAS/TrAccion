# Ciclo de vida del motor aislado

El supervisor recibe el estado de backups junto al estado SQLite, antes de cada respuesta. No autoriza reinicio con solicitudes pendientes, estado desconocido o revisiones sin respaldar. Un backup periódico que finaliza se observa en la siguiente operación (por ejemplo health-check); se prefiere bloqueo conservador a autorización prematura. Una caída en reposo solo permite recuperar con copia de estado confirmada sin pendientes; no se reproduce ninguna operación. Cierre fallido permite solicitar otro cierre, no reactivar escritura; si el proceso ya salió se permite salir sin afirmar cierre limpio. Reinicio solo se programa al finalizar cierre, o salida confirmada sin incertidumbre ni backups pendientes. El transporte tiene 120 s y la cola exterior aislada 150 s; el modo histórico conserva sus límites. No se mata un proceso bloqueado ni se altera el TTL. Pendientes pruebas reales SMB, corrección del contenido/confirmación de backups y política de restauración (PR B).
